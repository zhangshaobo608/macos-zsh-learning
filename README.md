# macOS Zsh 学习手册

面向初学者的交互式终端课程，适用于 macOS Sequoia 15.x 与默认 Shell `zsh`。

## 内容

- 1 节安全起步课程
- 4 个主题导学
- 39 个常用命令课程及配套案例
- `--help`、`--version` 与常用短参数说明
- PATH、管道、重定向和 nano 快捷键
- 学习进度、本地练习检查、巩固自测与 A4 打印版

## 使用

直接访问 GitHub Pages 在线学习，或下载仓库后用浏览器打开 `index.html`。网页为单文件，无需安装依赖，也可离线使用。

练习前请先按“开始这里”的说明建立独立练习目录。`rm` 不经过废纸篓，执行删除、移动或覆盖命令前请确认当前路径和目标。
