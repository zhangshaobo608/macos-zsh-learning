参数速查

常用参数与帮助

先认识常见模式，再回到具体命令确认真实含义。

写法：--help、--version 各自是一个完整参数，两个短横线和单词之间没有空格。它们是常见约定，并非所有 macOS 命令都支持。

查帮助和版本

01man ls
查看本机系统命令手册；按 q 退出。
02git --help
查看程序自己的帮助；是否支持需要看具体程序。
03git --version
查看程序版本；有些程序使用 -V，也有程序不支持。

帮助与版本

--help、--version 是常见约定，不是所有命令的统一参数。正确写法中两个短横线与单词之间没有空格。系统命令优先使用 man 命令名；例如 git --help、git --version、zsh --version。

命令作用示例

管道与重定向

| 传递输出：ls | grep txt
> 覆盖写入：echo 1 > a.txt
>> 末尾追加：echo 2 >> a.txt
< 文件作为输入：sort < a.txt

PATH

echo "$PATH" 查看原文。外部程序按目录从前到后查找；别名、函数和内建命令也会影响解析。用 command -v nano 看当前选中的命令。

参数与帮助

man ls 本机手册；git --help 帮助；git --version 版本。长参数中间无空格，且不是所有命令都支持。
ls -lh 易读大小；cp -n 不覆盖；rsync -n 试运行。

nano / pico

Ctrl+O 写出并按 Enter 确认，Ctrl+X 退出，Ctrl+K 剪切行，Ctrl+U 粘贴内部剪切区。版本可能不同，以底部提示为准。

本速查表不替代 man 命令名；不同 macOS 与工具版本的参数可能不同。
